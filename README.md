# Netflix Exploratory Data Analysis (EDA)

## Objective

The objective of this project is to perform Exploratory Data Analysis (EDA) on the Netflix dataset and identify trends, patterns, and insights related to movies and TV shows available on Netflix.

## Dataset

Netflix Titles Dataset from Kaggle

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Google Colab

## Tasks Performed

* Data cleaning and preprocessing
* Handling missing values
* Summary statistics
* Trend analysis
* Correlation analysis
* Data visualization

## Visualizations Created

* Content distribution by type
* Ratings analysis
* Release year trends
* Country-wise content analysis

## Key Insights

* Movies are more common than TV Shows on Netflix.
* Content production increased significantly after 2015.
* Certain ratings categories dominate Netflix content.
* The United States contributes the highest amount of content.

## Outcome

This project helped in understanding Netflix content trends and improved practical knowledge of data analysis and visualization techniques using Python.
